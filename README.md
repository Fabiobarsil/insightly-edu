# 🚀 Insightly Edu (CertusEdu)

Sistema de gestão educacional orientado a dados, desenvolvido com foco em organização acadêmica, integração de informações e suporte à tomada de decisão através de Business Intelligence.

---

## 🎯 Objetivo

Centralizar e estruturar dados acadêmicos (alunos, turmas, desempenho e processos administrativos), garantindo consistência das informações, visibilidade de indicadores e suporte à operação.

---

## 🧠 Principais Funcionalidades

- Gestão de alunos, turmas e estrutura acadêmica  
- Integração de dados entre diferentes módulos do sistema  
- Estruturação de dados para análise (modelo orientado a BI)  
- Dashboards para acompanhamento de indicadores  
- Monitoramento de inconsistências e validação de dados  
- Suporte a processos operacionais críticos  

---

## ⚙️ Tecnologias Utilizadas

- Frontend: React + TypeScript  
- Backend / Dados: Supabase (PostgreSQL)  
- BI: Power BI (modelagem, DAX e visualização)  
- Estilização: Tailwind CSS  
- Automação: JavaScript / TypeScript
